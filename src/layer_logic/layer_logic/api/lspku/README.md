# 逻辑综合工具 Tcl 命令文档

## 概述
本文档详细介绍了10个用于逻辑综合任务的Tcl命令，包括强化学习优化命令生成、精确综合方法、功耗驱动优化和功耗计算等功能。

## 环境配置
#### 1. 克隆代码库
git clone https://github.com/Logic-Factory/LogicFactory.git

#### 2. 进入目录并初始化子模块
cd LogicFactory
git submodule update --init --recursive

#### 3. 构建 Docker 镜像
docker build -t logic-factory:latest .

#### 4. 运行容器（关键：添加 --gpus all 启用 GPU 访问, RL算子需要GPU支持）
docker run -it --gpus all -v ../LogicFactory-hub:/workspace logic-factory:latest

#### 5. 进入容器后，正常构建
cd /workspace
mkdir -p build && cd build
cmake -G Ninja ..
ninja

#### 进入命令行界面 
./build/app/logicfactory


## 命令使用说明

以下是10个逻辑综合与功耗分析命令的详细使用说明：

注意：前两个RL命令需要先启动 rlgym 这一conda环境 

---

### 1. `rl_gene_basic`
使用basic特征模式（obs_dim=14）进行强化学习优化命令生成

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-test_list`      | 字符串  | 是   | 测试电路列表文件路径                     |
| `-result_log`     | 字符串  | 否   | 结果日志文件路径                         |
| `-agent_type`     | 字符串  | 否   | 智能体类型(PPO/greedy/random/anneal/abc_resyn) |
| `-model`          | 字符串  | 否   | PPO模型文件路径                          |
| `-fixed_mode`     | 整型    | 否   | 是否使用固定迭代模式(0/1)                |
| `-result_dir`     | 字符串  | 否   | 结果保存目录                             |
| `-test_dir`       | 字符串  | 否   | 测试电路目录                             |
| `-seq_length`     | 整型    | 否   | 每个电路最大迭代次数                     |
| `-converge_length`| 整型    | 否   | 收敛阈值                                 |
| `-initial_t`      | 浮点型  | 否   | 模拟退火初始温度                         |
| `-terminate_t`    | 浮点型  | 否   | 模拟退火终止温度                         |
| `-cool_ratio`     | 浮点型  | 否   | 模拟退火冷却比率                         |
| `-trace_dir`      | 字符串  | 否   | 跟踪文件目录                             |
| `-trace_file`     | 字符串  | 否   | 跟踪文件路径                             |

### 6. `ssv_incremental`
使用增量式SSV方法进行精确逻辑综合

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-functions`      | 字符串  | 是   | 布尔函数列表(十六进制字符串)              |
| `-r`              | 整型    | 否   | 综合步骤数                                |
| `-sub_r`          | 整型    | 否   | 子综合步骤数                              |
| `-sub_n`          | 整型    | 否   | 子函数输入数(默认自动计算)                |
| `-similar_method` | 字符串  | 是   | 相似函数生成方法(trunc/mute/mute_last/manual/random) |
| `-similar_option` | 字符串  | 否   | 相似函数生成选项                          |
| `-sat_output`     | 字符串  | 否   | 增量式SAT CNF编码保存路径                |
| `-circuit_output` | 字符串  | 否   | 解码后电路保存路径                       |
| `-solver`         | 字符串  | 否   | SAT求解器(kissat/cadical)                |
| `-num_decomposable`| 整型   | 否   | 可分解变量数量                           |
| `-random_tt`      | 字符串  | 否   | 用于综合的随机真值表                     |

---



### 7. `ssv_power`
生成功耗驱动优化的网表

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-output`         | 字符串  | 是   | 网表输出路径                           |
| `-num_inputs`     | 整型    | 是   | 输入变量数量                             |
| `-num_classes`    | 整型    | 是   | 输入概率离散化的类别数                   |
| `-average`        | 布尔    | 否   | 是否使用平均策略(默认:true)              |
| `-start_index`    | 整型    | 否   | 处理起始索引(默认:0)                     |
| `-partition_size` | 整型    | 否   | 最大处理函数数(默认:INT16_MAX)           |

---

### 8. `lut_rewrite`
使用最优库进行LUT重写

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-input`          | 字符串  | 是   | 输入BLIF文件路径(不含.blif扩展名)        |
| `-lib`            | 字符串  | 是   | 最优库文件路径                           |
| `-output_dir`     | 字符串  | 是   | 重写后网表输出目录                       |
| `-input_dir`      | 字符串  | 否   | BLIF文件输入目录                         |

---


### 9. `tech_mapping`

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-input`          | 字符串  | 是   | 输入网表文件(.blif)                      |
| `-output`         | 字符串  | 是   | 映射后网表输出文件(.v)                   |
| `-tech_lib`       | 字符串  | 是   | 工艺库文件(.lib)                         |

### 10. `calculate_power`

**参数说明：**
| 参数名            | 类型    | 必填 | 描述                                      |
|-------------------|---------|------|------------------------------------------|
| `-input`          | 字符串  | 是   | 输入网表文件(.blif)                      |
| `-tech_lib`       | 字符串  | 是   | 工艺库文件(.lib)                         |
| `-output`         | 字符串  | 否   | 功耗结果输出文件(为空则输出到控制台)     |

---

### 使用说明
1. **必填参数**：标记为"是"的参数必须提供
2. **文件路径**：建议使用绝对路径以确保兼容性
3. **SAT求解器**：支持`kissat`求解器

各命令的详细实现请参考对应类的源代码。
